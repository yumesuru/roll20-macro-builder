# Roll20 Macro Builder

Roll20 editor page overlay for creating divider, intro, and outro macros.

## Install

Install with Tampermonkey:

https://raw.githubusercontent.com/yumesuru/roll20-macro-builder/main/outputs/roll20-macro-builder.user.js

Tampermonkey updates are handled through the script metadata:

- `@updateURL`
- `@downloadURL`

When changing the script, bump `@version` so Tampermonkey can detect the update.
